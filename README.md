# 手寫筆記

給 iPad＋Apple Pencil 用的手寫筆記，免安裝、免帳號、免費。

打開：https://inotes-99.github.io/ink-notes/

## 開始用

1. 用 iPad 的 Safari 打開上面的網址
2. 按「分享」→「加入主畫面」
3. 之後從主畫面的「手寫筆記」圖示打開

## 有什麼

- 方格、橫線、點狀、空白紙；自然筆、圓珠筆、書法筆；粗細、顏色、壓感、穩定化
- 畫完停住不放會變成直線、圓、方形、三角形；在字上來回塗可以擦掉
- 螢光筆、橡皮擦、套索（移動、縮放、拷貝、換色）、文字、圖片
- 匯入 PDF 在上面寫；整本或單頁輸出成 PDF、PNG、ZIP
- 沒有網路也能用

## 筆記存在哪裡

筆記只存在你自己的裝置上，不會上傳到任何地方，別人看不到。
刪掉主畫面上的 App、換新 iPad 或重設 iPad，筆記就會不見，
所以請定期按書架上的「備份／還原」存一份備份檔到「檔案」或 iCloud。
